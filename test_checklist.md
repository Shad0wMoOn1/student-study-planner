# Проверки планировщика

Это план проверок, отметки выполнения заранее не выставлены.

- [ ] Задача с заполненными обязательными полями создается.
- [ ] Пустое название и название из пробелов отклоняются.
- [ ] Название длиной 121 символ отклоняется.
- [ ] Можно изменить дисциплину, срок и приоритет задачи.
- [ ] Удаление выполняется только после подтверждения.
- [ ] Поиск по названию и фильтр по дисциплине работают совместно.
- [ ] Незавершенная задача со вчерашним сроком выделяется как просроченная.
- [ ] Задача со сроком сегодня не считается просроченной.
- [ ] Готовая задача не считается просроченной.
- [ ] После перезагрузки страницы задачи сохраняются в localStorage.
- [ ] Экспорт JSON и последующий импорт восстанавливают задачи.
- [ ] Пустой список содержит понятное сообщение и действие добавления.

Данные sample_tasks.csv предназначены для демонстрации planner.py.
Они не подтверждают выполнение карточек Kaiten или готовность веб-интерфейса.
