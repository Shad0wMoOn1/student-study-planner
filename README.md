# student-study-planner

Учебный проект «Планировщик учебных задач студента» для практической работы №5
по организации репозитория в GitHub. Автор: Шемелин А.А., группа 5395,
кафедра ИС, СПбГЭТУ «ЛЭТИ», 2026 год.

## Назначение

Планировщик помогает учитывать задания по дисциплинам, отслеживать сроки
и изменять состояния задач: «Очередь», «В работе», «Готово».
Веб-версия планируется на HTML, CSS и JavaScript с хранением в localStorage.
Здесь находятся требования, схема интерфейса, руководство и вспомогательный
пример на Python. Полная веб-версия пока не реализована.

## Запуск примера на Python

Требуется Python 3. Сторонние библиотеки не нужны. После скачивания файла:

```sh
python3 planner.py
python3 planner.py --today 2026-11-26
```

Если в системе нет Python 3, для выполнения работы №5 его устанавливать
не требуется: все действия с репозиторием выполняются через сайт GitHub.
Для примера с CSV скачайте также `sample_tasks.csv` из `feature-materials`:

```sh
python3 planner.py --csv sample_tasks.csv --today 2026-11-26
```

Пример выводит задачи по возрастанию срока, затем приоритета. Незавершенная
задача просрочена, только если ее срок раньше даты проверки.
Демонстрационные записи не являются фактическим прогрессом проекта в Kaiten.

## Схема учебной работы с ветвями

- `main` — исходные материалы и основная линия проекта.
- `feature-materials` — дополнительные `sample_tasks.csv` и `test_checklist.md`.
- `feature-guide` — пояснение `version-control.txt` о контроле версий.

Обе дополнительные ветви создаются от исходной `main`.
Для переноса пояснения используется pull request с `base: main` и
`compare: feature-guide`. После слияния файл появляется в `main`, ветвь
`feature-guide` сохраняется. Материалы `feature-materials` в `main` не сливаются.

## Организация разработки

Процесс проекта из работы №1 организуется в Kaiten по Kanban.

Фактический прогресс оценивается по актуальной доске, а не по демоданным.
